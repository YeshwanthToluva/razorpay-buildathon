What the agent is, drawn from the code

Everything the agent can do, and everything standing in its way.

The model sits at the top. Nothing below it will act on the model's say-so. Each action it may propose is a node; under each one are the rules that can refuse it, and the tools it reaches if none of them do. Click an action to trace its route — click any rule to read it in the rulebook.
